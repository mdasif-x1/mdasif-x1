### 🚀 Featured Engineering Projects

#### 1. SANGYAN — Investor Safety System

**A public-interest financial scam analysis and investor awareness system.**

Built for the SANGYAN Investor Resilience Hackathon (SNTC, IIT BHU, in collaboration with SEBI and NSDL).

- **Problem:** Help retail investors examine potentially deceptive stock tips, investment claims, and advisory messages.
- **Rule-based analysis:** Java 21 and Spring Boot backend implementing deterministic heuristics for claim analysis, guaranteed-return language, and unauthorized-entity warning signals.
- **Client-side OCR:** Tesseract.js extracts text from screenshots in the browser, reducing the need to upload sensitive screenshots for OCR.
- **Verification:** Provides links to official resources for manual verification instead of claiming live regulatory verification.
- **Tech stack:** Java 21, Spring Boot, Docker, Next.js, TypeScript, Tailwind CSS, JUnit 5.

**Links:** [GitHub Repository](https://github.com/mdasif-x1/investor-safety-system) · [Live Application](https://investor-safety-system.vercel.app/)

```text
Screenshot / Message
        ↓
Browser-side OCR
        ↓
Spring Boot REST API
        ↓
Deterministic Rule Engine
        ↓
Structured Analysis & Defensive Guidance
```

#### 2. EchoRAG — Voice-Enabled Retrieval-Augmented Generation

**Collaborative team project for HH Goa 2026.**

- **My role:** Retrieval & Dataset Engineer.
- Prepared and indexed a retrieval corpus using Python and Hugging Face datasets.
- Worked with Qdrant vector search, `multilingual-e5-small` embeddings, and HNSW approximate nearest-neighbor indexing.
- The project benchmark records **6,098 passages**, **355 queries**, and **63.80 ms P50 retrieval latency**. Retain these figures only if they match the team's benchmark artifacts.

**Tech stack:** Python, Qdrant, Hugging Face Datasets, multilingual-e5-small, HNSW, Next.js, TypeScript.

**Links:** [Team Repository](https://github.com/mohdasif-v1/hh-goa-rag) · [Live Demonstration](https://ragingoa.mohdasifv1.dev/)

#### 3. PlacementDesk — Campus Placement Management Platform *(In Progress)*

**A transactional modular monolith for student and Training & Placement Officer workflows.**

- Designed around placement-drive publishing, student eligibility, applications, and offer tracking.
- Uses role-based access control for Student and TPO workflows.
- Uses relational persistence and Flyway migrations to manage schema evolution.
- Follows a modular-monolith approach to keep related business operations and transaction boundaries manageable.

**Tech stack:** Java 21, Spring Boot, Spring Security, Spring Data JPA, MySQL, Flyway, React.

**Status:** Under active implementation. Features and architecture are being developed and verified incrementally.

#### 4. Maansarovar Restaurant Platform

**Restaurant booking and business-management platform.**

- Reservation workflows and operating-hours enforcement.
- Spring Boot REST backend with JWT-secured administrative access.
- Media upload handling with file validation and database tracking.

**Tech stack:** Java, Spring Boot, Spring Security, MySQL, Flyway, Docker Compose, React, TypeScript.
